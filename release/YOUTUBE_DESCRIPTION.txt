TITLE:
FastAI v0.1.5: Unified Local & Cloud AI Engine for Java ⚡ (OpenRouter, Ollama, llama.cpp)

DESCRIPTION:
Showcasing FastAI v0.1.5 — the zero-dependency, hyper-fast Java AI client that unifies all major local and cloud LLM providers behind a single, elegant interface. Connect seamlessly to local engines (Ollama, llama.cpp GGUF) and cloud gateways (OpenRouter with 200+ models, Gemini, OpenAI, Claude, DeepSeek) in under 100ms.

TECHNICAL HIGHLIGHTS:
- OpenRouter Unified Gateway: Access over 200+ AI models (Claude 3.5 Sonnet, DeepSeek R1, Llama 3.3, GPT-4o) via `openrouter:model/name`.
- Local & Cloud Interchangeability: Switch between `ollama`, `llamacpp`, `openrouter`, and `gemini` by changing a single string parameter.
- Parameterized CLI Demo: Real-time token streaming with 3-parameter local mode (`run-demo.bat service model "payload"`) and 4-parameter cloud mode (`run-demo.bat service apikey model "payload"`).
- Zero-Dependency Core: Lightweight Java 17+ architecture with zero HTTP/JSON framework bloat and minimal memory overhead.

DEMO COMMANDS:
1. Local Ollama Mode:
   .\run-demo.bat ollama llama3.2:1b "Explain quantum physics in one short sentence."

2. OpenRouter Cloud Gateway Mode:
   .\run-demo.bat openrouter %OPENROUTER_API_KEY% anthropic/claude-3.5-sonnet "Write a haiku."
